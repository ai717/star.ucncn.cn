TOPIC // 01 OPTICAL RESOLUTION

遥感侦察卫星真能看清你吗？民用与军用分辨率解析

国际公开的民用遥感卫星（如欧空局 Sentinel-2 哨兵系列分辨率约 10 米，USGS Landsat-9 陆地卫星约 15 米），单像素相当于半个网球场大小，主要用于宏观地质与气象监测，绝无泄露个人面部或车牌风险；而商业高分遥感（如 WorldView-3、高景系列）0.3 米亚米级分辨率，已能清晰分辨车辆天窗与建筑物投射阴影。

TOPIC // 02 CSS TIANGONG TRANSIT

🇨🇳 中国空间站 (天宫) 肉眼反抓实操指南

天宫运行在倾角 41.5°、高度约 390km 的近地轨道。当过境最高仰角（Max Elevation）大于 35° 时，即便身处一线城市市中心灯火中，肉眼也能清晰目睹一颗明亮如金星的金色光点在 3~6 分钟内静默划过天顶。它无声音、无航行灯交替闪烁，呈现稳恒超高反光，是夜晚最引人注目的国家重器。

TOPIC // 03 ISS & HUBBLE OPTICS

🛰️ 国际空间站 (ISS) 与哈勃望远镜反光特性

国际空间站拥有足球场大小的柔性太阳能电池翼阵列，反射太阳光至地表的视星等可达 -3.5 等（远亮于全天最明亮的天然恒星天狼星 -1.46 等）。在城市 7~8 级 Bortle 光害区，普通肉眼极限星等约 +3.0 等，这意味着国际空间站过境在市中心商圈抬头即可瞬间捕捉。

TOPIC // 04 MOBILE ASTROPHOTOGRAPHY

📱 手机拍摄空间站划过夜空的专业摄影参数

拍摄空间站无需沉重单反。使用三脚架或将手机平稳固定，打开手机自带相机『专业模式』：ISO 感光度设定在 200~800，曝光快门设定为 4~10 秒，对焦锁定至无限远（Manual Focus ∞）。在过境最高仰角前 15 秒按下快门，即可捕获一条贯穿星空的耀眼金色航迹光线。

TOPIC // 05 SGP4 & PRIVACY FIRST

📐 SGP4 轨道动力学模型与纯前端无痕计算

太空偷窥局终端彻底摒弃服务器转发架构，将轨道摄动力学直接部署至浏览器客户端运行。基于北美防空司令部 (NORAD) 双行轨道根数 (TLE)，精细建模地球非球形重力场（J2~J4引力势）与稀薄大气阻力，在毫秒内完成地心坐标至观察者极坐标的投影，全程零隐私泄露、零痕迹存留。

TOPIC // 06 TARGET DISCRIMINATION

⚠️ 观星排雷：如何一眼辨识空间站与流星/客机/无人机

民航客机通常有规律闪烁的红绿防撞灯并伴随低沉轰鸣；无人机多在低空变速悬停；流星仅持续 0.5~2 秒且带燃烧烟迹；星链 (Starlink) 往往呈多星排队连珠线。而空间站则像一颗毫无声息、恒定发亮、匀速划破夜空的超级金色大星，通常需要 3~6 分钟完整飞越地平线。
